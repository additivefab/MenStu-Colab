# 科研仓库绑定

日期：2026-11-01，Asia/Shanghai。

## 使用方式

- 导师：打开学生档案，头部下方的“科研仓库”可直接打开仓库或管理绑定。
- 学生：自己的首页及“我的研究”显示同一入口。
- 每名学生保存一个主仓库，填写学生 GitHub 账号、GitHub 仓库首页 URL 和可见性记录。支持修改及解除；解除不删除 GitHub 仓库或历史进展链接。
- 本功能仅持久保存入口，不读取代码、不自动同步提交、不改变 GitHub 权限。私有仓库仍需在 GitHub 登录有权限的账号。
- 仓库设置独立于进展、月度确认、问题和任务。涉及代码的成果可在原进展表单附上具体 Commit 链接。

## 权限和存储

- `/api/student-repositories`：GET 按 `studentId` 读取；PUT 保存；DELETE 软解除。
- 学生只能管理自己，导师仅限有效分配范围，超级管理员可管理所有有效学生。双身份账号沿用当前身份范围；待授权、停用、未登录及范围外请求被拒绝。
- 所有响应 `private, no-store`；写入沿用同源验证。URL 仅接受规范 HTTPS GitHub 仓库首页，拒绝凭据、端口、编码混淆、查询参数及具体代码版本链接。
- 版本比较更新与审计放在同一 D1 事务中；陈旧页面返回 409，软解除保留版本。
- 新增三张表：`student_repository_bindings`、`student_repository_events`、`student_repository_rollouts`。查询按学生主键读取，不在页面切换时请求 GitHub。
