# 管理端与学生端界面简化

用户要求界面更简洁，后续明确本轮以电脑端为准。

## 修改范围

- 管理端合并标题、搜索与刷新，移除重复快捷入口和说明卡片。
- 五类状态人数保留为一条统计栏；点击即可筛选，不再重复放置状态下拉框。
- 学生列表收敛为学生、状态与原因、最近可信进展、下一步与期限、操作五列。论文与课题详情继续在学生侧栏查看。
- 学生端保留下一步、研究、进展、资料、导师五个入口，减少英文装饰标题、页面用途说明和重复账号区域。
- 研究页只显示一次论文名称，当前阶段与下一步保持可见，完整阶段列表按需展开。
- 进展历史和待补充材料默认收起。下一步与历史记录中的补证按钮自动展开外层和对应表单，并恢复焦点。
- 新进展表单中的阻塞、Git 链接、稿件编号合并为可选补充信息；附件、证据和必填字段保持可见。
- 账号与双身份切换、提交、审核、附件、权限和数据库接口保持原有功能。

## 验证范围

采用现有 React 组件与样式，在项目外使用匿名演示数据进行本地界面检查。演示数据和接口替身不包含在生产项目中，不连接生产数据库。

桌面检查包括管理端状态筛选、学生详情展开、Escape 关闭及焦点恢复、学生研究页、进展表单、补证深链，以及可选字段展开。用户要求后停止手机端专项工作。

现有自动化验证：TypeScript、ESLint、生产构建及 149 项测试。涉及旧界面文案的断言同步更新，权限和业务断言保留。

不将本地演示验证表述为真实飞书账号或生产写入验收。线上发布单独执行。
