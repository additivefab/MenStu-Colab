# 探研：科研进展管理系统

面向射线探伤与人工智能课题组的内部管理网站。系统不做学生排名或综合打分，只判断一个阶段内是否产生了可验证的新信息。

## V0.1 已实现

- 25 名匿名演示学生：12 名博士、13 名硕士
- 每人独立设置 7 / 14 / 21 / 30 天更新周期，最长 30 天
- 文献、实验、算法、数据、论文、复现和项目进展提交
- 文献阅读需同时提交可识别论文与阅读结论
- 导师四类审核：实质性进展、支持性工作、需要补充、非进展
- 30 / 60 / 90 天黄、橙、红预警
- 飞书登录、消息卡片、历史记录导入的配置入口
- GitHub 私有仓库只保存链接和提交号，完整代码保留给本地模型读取
- D1 持久化数据库与数据库迁移

## 本地运行

需要 Node.js 22.13 或更高版本：

```bash
npm install
npm run dev
```

打开 `http://localhost:3000`。首次请求会在本地 D1 中创建匿名演示数据。

## 验证

```bash
npm run lint
npm test
```

## 真实试用前还需配置

1. 用真实学生名单替换匿名数据，并为每人确认更新周期和当前阶段。
2. 在飞书开放平台创建企业自建应用，配置 App ID、App Secret、重定向域名和事件回调。
3. 将学生的飞书身份与系统学生记录绑定。
4. 对私有 GitHub 仓库安装只读 GitHub App；网站只接收元数据，本地 Agent 负责读取完整代码。

飞书密钥、GitHub 凭据和其他秘密信息不得写入仓库，应通过部署环境的加密变量配置。
